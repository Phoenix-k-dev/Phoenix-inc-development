1. Installation

1. Installation

Ajoutez Synapse via le bouton d’installation officiel. Accordez uniquement les permissions nécessaires aux fonctions que vous utilisez. Synapse s’appuie sur les commandes slash Discord.

Add Synapse through the official install button. Grant only the permissions required by the features you use. Synapse is driven through Discord slash commands.

2. Adaptive Builder

Le Builder est le cœur de Synapse. Il peut créer un serveur complet depuis un template ou analyser une structure existante pour compléter uniquement ce qui manque.

The Builder is Synapse’s core. It can create a complete server from a template or analyse an existing structure and only add what is missing.

  • Templates complets
  • Catégories, salons et rôles
  • Analyse de la DA existante
  • Ajouts ciblés sans doublons inutiles
  • Rollback et reset contrôlé
  • Complete templates
  • Categories, channels and roles
  • Existing style analysis
  • Targeted additions without unnecessary duplicates
  • Rollback and controlled reset

3. Ticket Studio

Ticket Studio analyse les tickets existants avant installation. Il peut conserver un panel existant, remplacer proprement une configuration et gérer des panels FR/EN réellement présents sans créer artificiellement un second salon.

Ticket Studio analyses existing tickets before installation. It can preserve an existing panel, replace a setup cleanly and manage real FR/EN panels without artificially creating a second channel.

/ticket scan/ticket setup/ticket creer/ticket couleurMulti staff roles

4. Permissions

Synapse distingue les commandes publiques, staff, responsables et administrateur Discord. Les permissions peuvent être ajustées par rôle.

Synapse separates public, staff, manager and Discord administrator commands. Access can be adjusted by role.

Les opérations destructives demandent une confirmation et respectent les protections Discord.
Destructive operations require confirmation and respect Discord protections.

5. Interserver

Interserver relie des salons entre plusieurs Discord grâce à des codes temporaires, des alias et un relais sécurisé par webhook.

Interserver links channels across several Discord servers using temporary codes, aliases and secure webhook relay.
